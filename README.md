## 🚀 Featured Projects

### 🚗 Open-Set Semantic Segmentation for Autonomous Vehicles
End-to-end perception pipeline for autonomous vehicle systems achieving **96% accuracy** on obstacle detection and traffic sign recognition. Implemented Vision Transformers and CapsNet architectures, simulated and validated using the CARLA autonomous driving simulator.  
`PyTorch` `Vision Transformers` `CapsNet` `OpenCV` `CARLA`

---

### 🔥 Real-Time Fire Detection & People Counting System
AI-powered fire safety system achieving **97% fire detection accuracy** (Inception V3) and **95% people counting accuracy** (MobileNet SSD). Deployed on Raspberry Pi for edge inference — real-time monitoring without cloud dependency.  
`TensorFlow` `Inception V3` `MobileNet SSD` `OpenCV` `Raspberry Pi`

---

### 🌿 IEEE-Published Weed Detection System
Object detection pipeline for precision agriculture using RetinaNet. Built end-to-end — from dataset curation and preprocessing to model training, evaluation, and results analysis on real agricultural field imagery.  
`PyTorch` `RetinaNet` `OpenCV` `Python`
